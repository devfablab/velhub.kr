# 데브허브 서비스 소개 페이지 기획 (확정)

> 2026-11-14 / 작성: Claude / 단계: 1. 기획 → 2. 디자인 → 3. 코드

## 1. 목적

- 데브허브를 처음 보는 사람이 한 페이지만 보고 "뭘 하는 곳이고, 나는 뭘 할 수 있는지" 알게 한다.
- 다 보고 나면 가입하거나, 블로그 또는 커뮤니티를 만들거나, 라운지를 둘러보게 한다.

## 2. 위치

- 페이지 이름: 처음 오셨나요?
- 주소: `/about` (사이트 주소로 못 쓰게 denylist에 추가함, proxy의 사이트 아닌 경로 목록에 추가함)
- 바닥글의 "데브허브 소개" 링크를 지금 글(`데브허브는 이런 곳이에요`)에서 이 페이지로 바꾼다.
- 로그인하지 않아도 볼 수 있다. 붙일 데이터는 없다.

## 4. 구성 원칙

- **사용법이 아니라 할 수 있는 것을 보여준다.** "블로그 관리의 기본설정에서" 같은 메뉴 위치, 순서 설명은 뺀다.
- **숫자와 조건은 뺀다.** 파일 크기, 글자 수, 하루 검사 횟수, 광고와 작은 커뮤니티를 여는 조건(가입 15일, 글 10개 등), 메시지 보관 기간 같은 것. 필요하면 "조건을 채우면"으로만 쓴다.
- **돈 이야기는 방법만.** 수수료(17%, 12%), 소장 가격(구독료의 27%), 멤버십 가격은 넣지 않는다.
- **카드마다 "자세히 보기"로 퀸시 글에 연결한다.** 소개 페이지는 짧게, 자세한 건 퀸시에서.
- **제목은 기능 이름보다 얻는 것으로.** 예: "공동 집필" → "다른 블로거와 한 편의 글을 함께 써요"
- **한 섹션에 카드 3~6개.** 넘으면 묶거나 뺀다.
- 위에서 아래로 "나는 뭘 할 수 있지?" → "특장점" → "자세히" → "안심" → "시작하기" 순서.
- "데브허브에만 있는", "유일한"처럼 다른 서비스에 없다고 단정하는 표현은 쓰지 않는다.
- 멤버십이 있어야 쓰는 기능에는 "멤버십 기능" 표시를 단다 (모먼트에 올리기, 서재 꾸미기, 내 도메인).

## 5. 섹션 구성

### 1) 첫 화면
- 작은 제목: 처음 오셨나요?
- 큰 제목: 콘텐츠를 중심으로, 각자의 공간을 만드는 곳
- 설명: 혼자 쓰는 1인 블로그부터 함께 쓰는 팀 블로그, 관심사를 나누는 커뮤니티까지. 나에게 맞는 공간을 만들어 보세요.
- 버튼: 시작하기(가입), 라운지 둘러보기
- 로그인한 사람에게는 시작하기 대신 블로그 만들기

### 2) 나에게 맞는 공간 고르기
네 장의 카드. 누르면 아래 해당 섹션으로 이동하거나 만들기 화면으로 간다.
- **혼자 쓰고 싶어요** → 1인 블로그: 내 이름으로 글을 쓰고 독자와 가깝게 만나요
- **함께 쓰고 싶어요** → 팀 블로그: 회사, 스터디, 동아리처럼 여럿이 함께 글을 써요
- **함께 모이고 싶어요** → 커뮤니티: 관심사가 같은 사람들과 글과 댓글로 이야기해요
- **읽고 싶어요** → 라운지: 여러 블로그와 커뮤니티의 글을 둘러보고 구독해요

### 3) 1인 블로그와 팀 블로그 한눈에 비교
퀸시 비교표를 줄여서 보여준다 (플랫폼 수수료 줄은 뺌).

| | 1인 블로그 | 팀 블로그 |
|---|---|---|
| 글을 쓰는 사람 | 나 | 운영자, 매니저, 멤버 |
| 팀원 초대와 역할 | | O |
| 팀원 소개 | | O |
| 블로그 구독, 후원 | O | |
| 연재 구독 | O | O |
| 공지사항, 공동 집필, 작은 커뮤니티 | O | |

- 아래에 한 줄: 1인 블로그로 시작해서 언제든 팀 블로그로 바꿀 수 있어요.

### 4) 데브허브의 특장점
데브허브를 고를 이유가 되는 기능. 페이지에서 가장 크게 보여준다. 카드 하나에 한 기능, 짧은 설명과 그림.
- 섹션 제목 후보: 데브허브라서 할 수 있는 것, 데브허브가 특별한 이유

1. **블로그 안의 작은 커뮤니티**: 내 블로그 구독자끼리 이야기 나누는 공간을 열어요. 오래 구독한 독자에게는 기간에 따라 멤버십팬 배지가 붙어요.
2. **공동 집필**: 다른 블로거와 한 편의 글을 함께 써요. 번갈아 고치고, 바뀐 곳을 비교하고, 채팅으로 이야기 나누다 공개하면 두 블로그에 함께 올라가요.
3. **워딩 프로파일러**: 혐오 표현과 차단 단어를 자동으로 걸러요. 띄어쓰기나 기호를 섞어 써도 찾아내요.
4. **연재 구독과 포스팅 소장**: 연재를 통째로 구독하거나, 읽고 싶은 글만 한 편씩 소장해요. 소장한 글은 계속 볼 수 있어요.
5. **라운지의 모먼트**: 새로 문을 연 사이트, 요즘 뜨는 글과 사이트가 모이는 곳. 내 사이트와 연재글을 직접 올릴 수도 있어요. (올리기는 멤버십 기능)
6. **커뮤니티 단체 채팅**: 커뮤니티 멤버끼리 실시간으로 이야기해요.

### 5) 쓰는 즐거움 (글쓰기)
블로그 / 커뮤니티 탭으로 나눈다.
- 공통: 마크다운과 일반 편집을 오가며 쓰는 에디터, 미리보기를 나란히
- 블로그 탭
  - 카테고리, 연재, 해시태그로 글 정리
  - 날짜와 시간을 정해 예약 출간
  - 구독 연재 글은 미리보기와 구독자용 본문을 따로
  - 저장 전에 맞춤법 검사, 고치고 싶지 않은 단어는 검사에서 빼두기
- 커뮤니티 탭
  - 일반, 갤러리, 유튜브, 피드 네 가지 게시판
  - 글에 투표 붙이기 (항목마다 이미지)
  - 선착순 또는 무작위 추첨 이벤트

### 6) 블로그를 내 방식대로
카드 5개.
- **내 도메인으로** (멤버십 기능): 내가 가진 도메인으로 블로그를 운영하고, 검색엔진과 Google Analytics를 연결해요. 공유할 때 보이는 이미지는 글마다 자동으로 만들어져요.
- **댓글 방식 고르기**: 데브허브 댓글, Disqus, Giscus 중에서 골라요. 개발 블로그라면 Giscus로 GitHub Discussions를 댓글로 쓸 수 있어요.
- **공지사항**: 독자에게 알릴 소식을 따로 모아 둬요.
- **팀원 소개**: 팀 블로그는 팀원마다 학력, 수상, 프로젝트, 경력을 보여줄 수 있어요.
- **광고와 상품**: 블로그에 광고를 붙이고, 연재글에 소개하고 싶은 상품을 걸어요.

### 7) 커뮤니티를 내 방식대로
카드 6개.
- **가입 받기**: 오픈가입이나 초대가입, 가입 신청 기간과 가입 질문까지 정해요.
- **글쓰기 조건**: 새 멤버가 언제부터 글과 댓글을 쓸 수 있는지 정해요.
- **멤버 등급**: 활동에 따라 자동으로 올라가는 등급을 만들어요.
- **매니저**: 커뮤니티 전체부터 게시판 하나까지 나눠 맡겨요.
- **비공개 게시판**: 멤버와 운영진이 1:1로 이야기하는 문의 창구를 둬요.
- **꾸미기와 통계**: 홈 화면과 메뉴, 외부 링크(디스코드, 카카오톡)를 정하고 접속자와 가입자 흐름을 봐요.

### 8) 창작을 이어가는 방법
카드 3개 + 한 줄.
- **구독**: 블로그나 연재를 매월 구독해요.
- **소장**: 읽고 싶은 글만 한 편씩 사서 계속 봐요.
- **후원**: 블로그, 연재, 글을 응원하며 후원하고 후원 댓글을 남겨요.
- 한 줄: 작가 신청을 하면 받은 금액을 정산받을 수 있어요. 결제와 환불 내역은 마이허브에서 확인해요.

### 9) 안심하고 머무는 곳
카드 4개.
- **워딩 프로파일러**: 혐오 표현이 들어간 글, 댓글, 채팅을 자동으로 걸러요. 운영자는 우리 사이트에서 막을 단어를 더할 수 있어요.
- **신고와 권리보호**: 문제가 있는 콘텐츠는 신고센터로, 내 권리를 침해한 글은 권리보호센터로.
- **소명**: 내 콘텐츠가 신고로 제한됐다면 소명 의견을 낼 수 있어요.
- **본인 확인과 결제 보호**: 결제나 커뮤니티 개설처럼 필요한 순간에만 본인인증을 하고, 미성년 회원의 결제를 보호해요.

### 10) 내 활동은 한곳에
카드 3개.
- **마이허브**: 참여한 사이트, 좋아요, 저장한 글, 읽은 글, 즐겨찾는 블로그, 구입내역을 모아 봐요.
- **작가의 서재, 독자의 서재**: 여러 사이트에 쓴 내 글을 한곳에 모으고, 좋아하는 작가를 팔로우해요. (서재 꾸미기와 독자의 서재는 멤버십 기능)
- **모먼트에 알리기** (멤버십 기능): 내 사이트와 연재글을 라운지에 올려 더 많은 사람에게 보여줘요.

### 11) 함께 만드는 데브허브
카드 2개.
- **기능 연구소**: 바라는 기능을 제안하고, 진행 상태를 지켜봐요.
- **컨시어지**: 자주하는 질문, 문의, 채널톡 상담으로 언제든 물어보세요.

### 12) 마지막
- 제목: 천천히 오래 남는 콘텐츠를 위해
- 설명: 글을 쓰고 싶은 사람도, 커뮤니티를 만들고 싶은 사람도, 좋아하는 콘텐츠를 오래 읽고 싶은 사람도 편하게 머물 수 있는 곳을 만들어가고 있어요.
- 버튼: 블로그 만들기, 커뮤니티 만들기, 라운지 둘러보기

## 6. 화면 동작

- 맨 위에 섹션 바로가기(블로그, 커뮤니티, 글쓰기, 수익, 안심)를 두고, 스크롤해도 따라오게 한다.
- 4) 특장점은 카드를 크게, 그림과 함께.
- 5) 글쓰기는 블로그 / 커뮤니티 탭.
- 모바일은 카드를 한 줄에 하나씩.
- 라이트, 다크 모드 모두 지원.
- 그림: 첫 화면과 특장점 카드 6개에만 도형으로 그린 그림 (사진, 화면 캡처는 쓰지 않음). 나머지 섹션은 아이콘만.

## 8. 정한 것

- 4) 여섯 개는 특장점으로 넣는다 (다른 곳에 없다는 뜻 아님)
- 멤버십 기능 표시: 한다
- 디자인: 피그마. 클로이가 데스크톱, 모바일 프레임을 나눠 공유하면 그 안에서 작업
